Yoga Master — Online Yoga Learning Platform

Yoga Master is an online yoga learning platform designed to help users discover yoga classes, learn from instructors, and manage their yoga learning journey. The platform includes dedicated interfaces for users, instructors, and administrators, with features for class management, instructor applications, and content approval.

Overview

Yoga Master aims to make yoga education more accessible through a centralized platform where learners can explore classes and instructors, access their purchased classes, and manage their learning activities. Instructors can apply to teach and submit classes for approval, while administrators oversee users, instructors, classes, and publication workflows.

The project follows a role-based approach to provide different functionality and access levels for each type of user.

Features

User Module

- Browse available yoga classes, courses, and instructors.
- Explore yoga learning opportunities based on individual interests.
- Purchase classes through the checkout workflow.
- Access purchased classes.
- View payment history.
- Apply to become an instructor after developing the required skills.
- Access AI-assisted guidance and offline workout resources, where implemented.

Instructor Module

- Apply for instructor access.
- Create and submit yoga classes for review.
- Track class approval and publication status.
- Manage submitted classes through the instructor workflow.

Administrator Module

- View platform statistics, including users, instructors, and classes.
- Manage users and instructor accounts.
- Review instructor-submitted classes.
- Approve or reject class submissions.
- Manage class publication workflows.

Platform Highlights

- Role-based functionality for users, instructors, and administrators.
- Centralized class and instructor management.
- Structured class approval and publication workflow.
- Online learning and workout support.

Getting Started

Follow these steps to obtain a local copy of the project.

Prerequisites

Install the runtime, package manager, database, and development tools required by the project.

Installation

1. Clone the repository:
   
   git clone https://github.com/Rushermanz/Yoga-app.git

2. Navigate to the project directory:
   
   cd Yoga-app

3. Install the dependencies required by the frontend and backend.

4. Configure the required environment variables and database settings, if applicable.

5. Start the frontend and backend using the development commands specified by their respective configurations.

Note: Refer to the configuration files inside "Frontend/" and "Backend/" for the exact installation and startup commands.

Application Workflow

1. A user registers or signs in to the platform.
2. The user browses available yoga classes and instructors.
3. The user completes the purchase process when purchasing is enabled.
4. The user accesses their purchased learning content.
5. An aspiring instructor submits an application to teach.
6. An authorized administrator reviews submitted classes and manages publication.
7. Instructors manage their classes according to their assigned permissions.
